ERP-система для зоопарка

Это простая консольная программа на Java, которая моделирует работу базовых процессов зоопарка с применением принципов SOLID.
Система автоматизирует:
- кормление животных;
- медицинские проверки;
- уборку вольеров;
- формирование отчетов о животных.

Принципы SOLID в коде:
1. SRP — Каждый класс выполняет отдельную задачу: животные (Animal) — только данные, сотрудники (Staff) — действия, отчёт (ReportGenerator) — формирование отчёта.
2. OCP — Новые виды животных можно добавить без изменения существующего кода.
3. LSP — Любой подкласс Animal безопасно заменяет базовый класс.
4. ISP — Мелкие интерфейсы (Feedable, Healable, Cleanable) — классы реализуют только нужные.
5. DIP — Код зависит от абстракций (интерфейсов), а не от конкретных реализаций.

Как запустить:
1. Склонируй репозиторий:
   git clone https://github.com/ansmn/zoo-erp.git
2. Убедись, что установлен JDK.
3. Запусти класс Main.java.
